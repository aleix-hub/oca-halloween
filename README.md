# L’oca encantada · Sant Josep

Joc d’educació física de Halloween: 1–8 equips, 63 caselles, dau, fitxes animades i reptes ampliats.

## Publicar a GitHub Pages

1. Descomprimeix el ZIP.
2. Crea un repositori públic a GitHub, per exemple `oca-halloween`. Activa Add README.
3. Al repositori, selecciona Add file > Upload files.
4. Puja index.html, app.js i castle.png directament a l’arrel del repositori. Pots pujar també aquest README i .nojekyll.
5. Prem Commit changes.
6. Obre Settings > Pages.
7. A Source, selecciona Deploy from a branch.
8. Tria main i /(root), i prem Save.
9. Quan acabi la publicació, prem Visit site a Settings > Pages.

No pugis el ZIP directament ni deixis index.html dins d’una subcarpeta.
No cal instal·lar res ni configurar cap procés de compilació.

La partida es desa al navegador de cada dispositiu. Els equips comparteixen pantalla, no se sincronitzen entre dispositius.
Les tipografies es carreguen des de Google Fonts; si no hi ha connexió es fan servir les fonts alternatives.
